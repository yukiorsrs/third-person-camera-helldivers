# Third Person Camera (HD2 Style) for HELLDIVERS

Source code of the installer for the **Third Person Camera (HD2 Style)** mod for HELLDIVERS (Dive Harder Edition).

The installer patches the player's own game files. It does not contain or distribute any game files:

- `installer.py` is the whole installer (GUI, game detection, patching, backup and uninstall).
- `data/lua/*.bin` are the mod's compiled scripts, which replace scripts in the game's script bundles.
- `data/sky/*.dds` are the sky textures added to the biome bundles. The night sky is generated by `installer.py` at install time.
- `data/originals.json` lists the game files the mod touches with their SHA-256. The installer refuses to patch anything that does not match, so it never patches an unknown game version.

## What the installer does

1. Finds HELLDIVERS through Steam (app manifest, library folders, uninstall entry).
2. Closes the game if it is running.
3. Checks each target bundle against its known SHA-256.
4. Writes patched copies next to the originals. Only when every file has passed does it move the originals into `contents/hd2cam_backup` and the patched files into place.
5. **Uninstall** moves the originals back and deletes the backup folder.

It has no network access, no registry writes and does not touch any file outside the game's `contents` folder.

## Build

Requirements: Windows, Python 3.12, PyInstaller 6.22.3.

```
python -m pip install pyinstaller==6.22.3
python -m PyInstaller --noconfirm --onedir --windowed --noupx --name ThirdPersonCamera_Installer --version-file version_info.txt --add-data "data;data" installer.py
```

The installer is created in `dist/ThirdPersonCamera_Installer/`.

You can also run it without building: `python installer.py` (GUI), or `python installer.py --install` / `--uninstall` (silent).
